# Auto Clicker

Простий автоклікер для Windows з темним інтерфейсом: гнучкий інтервал кліків, гаряча клавіша старт/стоп, фіксована позиція курсора або пошук по зображенню, а також перемикач мови інтерфейсу (UA / RU / EN).

## Встановлення (Windows)

Готовий інсталятор лежить на сторінці [Releases](https://github.com/to0-young/auto-clicker/releases) — Python встановлювати не потрібно.

1. Завантаж **`AutoClickerSetup.exe`** з останнього релізу.
2. Запусти файл і пройди майстер встановлення (можна лишити позначку **"Create a desktop shortcut"**).
3. Готово — ярлик з'явиться на робочому столі та в меню Пуск, є деінсталятор.

> Windows SmartScreen або антивірус можуть попередити про незнайомий файл — це нормально для непідписаних `.exe`. Натисни "Докладніше" → "Виконати в будь-якому разі".

## Автоклікер не працює в грі (наприклад, Lineage 2)

Деякі ігри запускаються з підвищеними правами, і Windows блокує кліки від процесів без прав адміністратора. Установлений Auto Clicker сам запитує ці права при запуску (з'явиться запит UAC) — просто підтверди його.

## Як користуватись

- **Interval Configuration** — інтервал між кліками (год/хв/сек/мс) і випадкове відхилення.
- **Click Options** — кнопка миші (ліва/права/середня) і тип кліку (одинарний/подвійний/утримання).
- **Click Repeat** — повторювати задану кількість разів або нескінченно, поки не зупинено.
- **Cursor Position** — клікати в поточній позиції курсора, у фіксованих координатах, або шукати клік по зображенню на екрані.
- Кнопка **Start/Stop** внизу або гаряча клавіша (за замовчуванням `F6`, можна перепризначити кнопкою **Record Hotkey**).
- Три кнопки **UA / RU / EN** вгорі вікна перемикають мову інтерфейсу миттєво.

## Збірка з коду (для розробників)

```
pip install -r requirements.txt
python main.py
```
